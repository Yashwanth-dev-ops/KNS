# KNS Construction and Real Estate: 3D world

A Next.js (static export) + react-three-fiber site: enter through a gate with the KNS logo and explore open plots, turnkey construction, finishing, a ready-to-move duplex, apartments and the office.

```
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
```

See `docs/PROJECT.md` for the journey map, research plan, QA checklist and handoff.
